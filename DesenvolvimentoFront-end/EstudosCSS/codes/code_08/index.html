Exemplo de imagens

object-fit

A imagem se ajusta ao tamanho definido usando object-fit: cover.

Exemplos de valores

  • object-fit: fill; — preenche o espaço, podendo distorcer a imagem.
  • object-fit: contain; — mantém a imagem inteira dentro do espaço.
  • object-fit: cover; — preenche o espaço e corta o excesso.
  • object-fit: none; — mantém o tamanho original da imagem.
  • object-fit: scale-down; — escolhe entre none e contain.

object-position

A imagem é posicionada no canto superior direito usando object-position: right top.
