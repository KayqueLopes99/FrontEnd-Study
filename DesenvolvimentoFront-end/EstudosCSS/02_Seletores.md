## Seletores
- Define como os elementos HTML serão selecionados para aplicar estilos CSS.

### Seletor por Tipo
- Busca elementos por uma tag HTML específica.
- Exemplo: `p` seleciona todos os elementos `<p>`.

### Seletor por ID (`#`)
- Busca elementos através do atributo `id`.
- Exemplo: `#menu` seleciona o elemento que possui `id="menu"`.

### Seletor por Classe (`.`)
- Busca elementos através do atributo `class`.
- Exemplo: `.destaque` seleciona todos os elementos que possuem a classe `destaque`.

### Seletor Universal (`*`)
- Seleciona todos os elementos HTML.
- Exemplo: `*` aplica o estilo a todos os elementos da página.

### Seletor de Atributo (`[atrib]`)
- Seleciona elementos que possuem um atributo específico no documento HTML.
- Também é possível buscar atributos com um valor específico.
- Exemplos: `[disabled]` seleciona elementos com o atributo `disabled`; `[type="text"]` seleciona elementos cujo atributo `type` tem o valor `text`.
